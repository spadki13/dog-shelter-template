# Contributing

Thanks for your interest in improving this template.

## Setup

Follow the [Getting Started](README.md#getting-started) section in the README.

## Before opening a PR

- `pnpm lint`
- `pnpm typecheck`
- `pnpm test`
- Run `pnpm generate:types` if you changed any collection/global schema

## Commit style

Conventional commits (`feat:`, `fix:`, `chore:`, `docs:`, `refactor:`, `test:`).
